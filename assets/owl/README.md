# Watchtower owl variant

Created on 6 November 2026 with the built-in image generator. This painted
sentinel owl uses ivory and slate-blue feathers, gold edges and turquoise eyes.
The exact prompt and style references are in `logo-prompts.json`.

- `logo-master.png`: original generated artwork, 1254px square.
- `logo-1024.png`: 1024px square export.
- `logo.png`: 512px square export.

The PNGs keep the opaque midnight-navy background and are resized from the
master. This is a separate artwork variant. The app's current icon assets
remain in the parent directory.
